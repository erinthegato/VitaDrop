Send files to your Vita

Pick photos, videos or anything from Files.

Add "Send to Vita" to the Share menu

Set this up once, then send anything with Share → Send to Vita. No QR code needed.

  1. Open the Shortcuts app and tap +. Tap the name at the top and call it Send to Vita.
  2. Tap the name again → Details → turn on Show in Share Sheet.
  3. Add the action Repeat with Each and set it to Shortcut Input.
  4. Inside the repeat, add Get Contents of URL. Set the URL to http://vitadrop.local:8080/upload
  5. Tap Show More: set Method to POST. Under Headers, add X-File-Name with the value Repeat Item, then tap it and choose Name. Set Request Body to File and pick Repeat Item.
  6. After End Repeat, add Show Notification with the text Sent to Vita. Tap Done.

The first time, allow the shortcut to connect and to find devices on your network. If it can't find vitadrop.local, use the address under the QR code on the Vita instead, plus upload at the end.
